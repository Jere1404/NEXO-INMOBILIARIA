# Fotografías de referencia de propiedades

Todavía no hay fotografías en esta carpeta. No agregar archivos sin procedencia y permiso de uso comprobables. Las futuras imágenes serán ilustrativas: no representan ofertas reales ni inmuebles ubicados necesariamente en las zonas del catálogo.

Organizar las imágenes por el identificador estable del JSON, desde `nexo-001/` hasta `nexo-012/`. Para cada propiedad se proponen `principal-480.webp`, `principal-960.webp` y `principal.jpg` como respaldo JPEG; podrán agregarse variantes JPEG si hacen falta. Los nombres son una convención futura, no referencias a archivos existentes. Las carpetas individuales están preparadas localmente; Git solo las conservará cuando contengan archivos.

Usar encuadre 4:3, optimización con calidad revisada visualmente y dimensiones reales en los metadatos. Registrar autor, página original, licencia y permiso aplicable en `docs/RECURSOS.md` antes de incorporar cada recurso. Ver el contrato técnico de `imagen` en `docs/IMAGENES-PROPIEDADES.md`.
